# 채권자목록 정리 프로그램 (1단계)

개인회생 사건의 채권자목록을 정리하고, 누락을 점검하고, 한글(HWP)·엑셀로 출력하는 법무법인 내부용 프로그램입니다.
GPT·인터넷을 쓰지 않으며, 모든 자료는 이 PC의 `data/cases.db` 파일 하나에만 저장됩니다.

## 설치·실행 (Windows)

1. Python 3.11 이상 설치: https://www.python.org/downloads/
   설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 이 폴더를 원하는 곳(예: `C:\채권자목록`)에 풀어 둡니다.
3. **`실행.bat` 더블클릭.** 처음 한 번은 필요한 프로그램을 설치하느라 몇 분 걸립니다.
4. 브라우저가 자동으로 열립니다(안 열리면 http://localhost:8501).
5. 처음 실행하면 **사무원 계정**과 **변호사 계정**을 만듭니다.

끝낼 때는 검은 창을 닫으면 됩니다. 이 PC에서만 열리고, 같은 사무실의 다른 PC에서는 접속할 수 없습니다.

## 업무 순서

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | 사건 목록 | 새 사건 등록 |
| 2 | 사건 기본정보 | 채무자 정보, 관할 법원, 담당 변호사, 목록 기준일 |
| 3 | 채무 문진 | 채무 종류별로 있음/없음/모름 체크 |
| 4 | 신용정보 대조 | 신용정보조회서 PDF를 올려 자동으로 읽거나 직접 입력 (목록에 없는 기관은 한 번에 채권자로 추가 가능) |
| 5 | 채권자 입력 | 채권자별·계약별로 원금, 이자, 지연손해금, 기준일, 발생일, 양도 이력 입력 |
| 6 | 발급대행 요청 목록 | 대행 업체에 보낼 엑셀 출력, 기관별 수령 체크 |
| 7 | 누락 점검 | 경고를 고치거나, 사유를 적고 '확인함' |
| 8 | 미리보기·출력 | 검토 요청 → 변호사 확인 완료 → HWP·엑셀 출력 |
| 9 | 변경 기록 | 누가 언제 무엇을 바꿨는지, 누가 확인했는지 |

### 누락 점검 규칙
1. 신용정보조회서에 있는데 채권자목록에 없는 기관 (`(주)`, `주식회사`, 띄어쓰기 차이는 무시)
2. 문진에서 "있음"인데 그 분류로 등록된 채권이 없는 항목
3. 부채증명서가 아직 "수령"이 아닌 채권자
4. 양도 전 기관과 양도 후 기관이 둘 다 채권자로 등록된 경우 (중복 의심)
5. 채권마다 금액 기준일이 다른 경우
6. 원금·이자·지연손해금·발생일·기준일이 비어 있는 채권 (0원으로 계산하지 않고 "미확인")

### 변호사 확인 규칙
- "변호사 확인 완료"는 **변호사 계정에서만**, **처리 안 된 경고가 0건일 때만** 할 수 있습니다.
- 확인 완료 뒤 채권 내용을 고치면 자동으로 "작성 중"으로 돌아갑니다 (부채증명서 수령 체크는 예외).
- 확인 전에 출력한 파일은 제목과 파일 이름에 **초안**이 붙습니다.
- 합계는 확인된 금액만 더하고, 비어 있는 칸은 "미확인 n건"으로 따로 표시합니다.

## 신용정보조회서 PDF 자동 읽기 (2단계)

신용정보 대조 화면 → "PDF에서 자동으로 읽기" → 파일 올리기 → 읽기.

- 표가 있으면 머리글(기관명·잔액·일자·상품 등)로 열을 찾아 읽고, 표가 없으면 한 줄씩 읽습니다.
- `(단위: 천원)`·`만원` 표시를 찾아 **원 단위로 바꿉니다.** 금액 열은 잔액 → 연체금액 → 금액 순으로 고릅니다.
- **조회기록**(다른 기관이 조회한 기록)은 채권자가 아니므로 읽지 않습니다. 합계·소계 줄도 뺍니다.
- 처음부터 빼 두는 항목: 잔액 0원, 연체정보에 다시 나온 같은 기관, 완전히 같은 중복. 필요하면 체크해서 가져오면 됩니다.
- 읽은 결과는 **바로 저장되지 않습니다.** 원문 그림(읽은 위치에 초록·회색 표시)과 대조해 고르고, 틀린 칸은 표에서 고친 뒤 가져오세요.
- 이미 있는 같은 기관·같은 금액은 다시 넣지 않습니다. 가져온 기록은 변경 기록에 남습니다.
- 비밀번호가 걸린 PDF는 비밀번호를 넣고 읽으면 됩니다. 파일은 디스크에 저장하지 않습니다.
- 글자가 없는 스캔본 쪽은 읽지 못하고 알려 줍니다 (3단계 OCR 예정).

발급처(한국신용정보원, NICE, KCB 등)마다 양식이 달라 잘 안 읽히는 경우가 있습니다. 그때는 `core/credit_pdf.py` 위쪽의
키워드 목록(`INST_HEADERS`, `AMOUNT_HEADERS` 등)을 고치거나, 개인정보를 가린 샘플로 양식에 맞춰 조정하세요.

## HWP 출력

한글(한컴오피스)이 설치된 PC에서만 됩니다. 두 가지 방식이 있습니다.

**A. 양식 없이 (기본)**: 프로그램이 표를 만들어 HWP로 저장합니다.

**B. 사무소 양식 사용**: `templates/채권자목록_양식.hwp` 파일을 두면 그 양식의 누름틀에 내용을 채웁니다.
양식 만드는 법: 한글에서 양식을 열고, 채울 자리에 `입력 → 개체 → 누름틀`을 넣은 뒤 누름틀 고치기에서 **필드 이름**을 아래처럼 지정합니다.

- 머리글: `사건번호`, `채무자`, `법원`, `기준일`, `작성일`, `초안표시`
- 표의 한 행: `번호`, `채권자`, `주소`, `연락처`, `원인`, `발생일`, `원금`, `이자`, `지연손해금`, `합계`, `산정기준일`, `비고`
  → 이 행을 필요한 줄 수(예: 40줄)만큼 복사해 두세요. 같은 이름의 누름틀을 위에서부터 차례로 채웁니다.
- 합계 행: `합계_원금`, `합계_이자`, `합계_지연손해금`, `합계_합계`, `미확인건수`

한글이 "파일에 접근하려 합니다" 창을 띄우면 "모두 허용"을 누르세요. 이 창을 없애려면 한컴의
보안 모듈(FilePathCheckerModule)을 등록하면 됩니다.

## 백업
`백업.bat`을 실행하면 `backup` 폴더에 날짜별로 복사됩니다. 의뢰인 정보가 들어 있으므로 백업 파일도 사무소 밖으로 가져가지 마세요.

## 설정 바꾸기
- 법원 목록·법원별 메모: `config/courts.json`
- 문진 항목: `config/questionnaire.json` (항목을 지우면 기존 사건의 분류 표시가 사라지니 추가만 권장)
