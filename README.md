# 개인회생 업무 자동화 프로그램

법무법인 내부에서 개인회생 사건의 **채권자목록 정리·누락 점검, 신용정보조회서·부채증명서 읽기, 보정명령 관리,
변제계획안 계산**을 돕는 프로그램입니다. 만든 문서는 한글(HWP)·엑셀로 출력합니다.

- 사무원과 프로그램이 자료와 초안을 만들고, **판단과 확정은 변호사 계정으로만** 합니다. 누가 언제 무엇을 바꾸고 확인했는지 모두 기록됩니다.
- GPT 등 외부 AI를 쓰지 않습니다. 모든 자료는 이 PC의 `data/cases.db` 파일 하나에만 저장되고, 프로그램은 이 PC에서만 열립니다.
- 계산과 자동 읽기 결과는 초안입니다. 최종 판단은 변호사가 합니다.

## 설치 (처음 한 번)

### 준비물

| 항목 | 필요 여부 | 용도 |
|---|---|---|
| Windows 10 또는 11 (64비트) | 필수 | |
| Python 3.12 (3.11~3.13) | 필수 | 프로그램 실행 |
| 인터넷 연결 | 처음 설치·업데이트 때만 | 필요한 부품 내려받기 (사용 중에는 필요 없음) |
| 한컴오피스 한글 | 선택 | HWP 출력. 없으면 엑셀·HTML로만 출력 |
| Tesseract OCR | 선택 | 스캔본·사진 부채증명서와 보정명령 읽기. 전자 발급 PDF는 없어도 읽음 |

### 1. Python 설치

1. https://www.python.org/downloads/windows/ 에서 **Python 3.12**의 "Windows installer (64-bit)"를 받습니다.
2. 설치 파일을 실행하고, 첫 화면 아래쪽의 **"Add python.exe to PATH"를 꼭 체크**한 뒤 "Install Now"를 누릅니다.
3. 확인: 시작 메뉴에서 "명령 프롬프트"를 열고 `python --version`을 입력해 `Python 3.12.x`가 나오면 됩니다.

### 2. 프로그램 받기

1. GitHub 저장소 페이지(https://github.com/YoungJun-Hwang/individual-rehabilitation-rpa)에서
   초록색 **Code → Download ZIP**을 누릅니다. 비공개 저장소라면 접근 권한이 있는 계정으로 로그인해야 합니다.
2. 받은 ZIP 파일을 **오른쪽 클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인**. (안 하면 실행할 때 Windows가 경고합니다.)
3. 압축을 풀고, 폴더를 알아보기 쉬운 곳으로 옮깁니다. 예: `C:\개인회생`
   - 바탕화면·다운로드 폴더보다 `C:\` 바로 아래가 좋습니다 (OneDrive로 동기화되는 폴더는 피하세요. 의뢰인 자료가 클라우드로 올라갑니다).
   - 압축을 풀면 폴더 이름이 `individual-rehabilitation-rpa-main`이 됩니다. 이름은 바꿔도 됩니다.

git을 쓴다면 `git clone https://github.com/YoungJun-Hwang/individual-rehabilitation-rpa C:\개인회생` 으로 받아도 됩니다.

### 3. (선택) Tesseract OCR 설치 — 스캔본을 읽으려면

1. https://github.com/UB-Mannheim/tesseract/wiki 에서 Windows용 설치 파일(64bit)을 받아 실행합니다.
2. 설치 중 "Choose Components" 화면에서 **Additional language data → Korean을 꼭 체크**하세요.
3. 설치 위치는 기본값(`C:\Program Files\Tesseract-OCR`)을 그대로 두면 프로그램이 알아서 찾습니다.
   다른 곳에 설치했으면 Windows 환경 변수 `TESSERACT_CMD`에 `tesseract.exe`의 전체 경로를 넣으세요.

### 4. 처음 실행

1. 프로그램 폴더의 **`실행.bat`을 더블클릭**합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
2. 검은 창이 열리고 필요한 부품을 설치합니다. **처음 한 번은 몇 분** 걸립니다 (인터넷 필요).
3. 설치가 끝나면 브라우저에 프로그램이 열립니다. 안 열리면 브라우저 주소창에 **http://localhost:8501** 을 입력하세요.

### 5. 계정 만들기

처음 열면 "처음 설정" 화면이 나옵니다. **사무원 계정**과 **담당 변호사 계정**을 하나씩 만드세요 (비밀번호 4자 이상).

- '변호사 확인 완료', 보정서 승인, 변제계획안 확정은 **변호사 계정에서만** 됩니다.
- 계정은 나중에 변호사 계정으로 로그인해 왼쪽 아래 **계정 관리**에서 더 만들 수 있습니다.
- **비밀번호 바꾸기**: 누구나 **계정 관리 → 내 비밀번호 바꾸기**에서 바꿀 수 있습니다 (지금 비밀번호 필요).
- **비밀번호를 잊었을 때**:
  1. 변호사·관리자 계정으로 로그인해 **계정 관리 → 다른 사람 비밀번호 초기화**에서 임시 비밀번호를 정해 줍니다.
     그 사람은 임시 비밀번호로 로그인하면 바로 새 비밀번호로 바꾸는 화면이 나옵니다.
  2. 모든 계정의 비밀번호를 잊었다면, 프로그램을 설치한 PC에서 **`비밀번호_초기화.bat`**을 실행해
     계정을 고르고 임시 비밀번호를 정합니다. 이 도구는 그 PC에서만 쓸 수 있습니다.
- 비밀번호 변경·초기화는 누가 언제 했는지 기록됩니다 (비밀번호 자체는 기록하지 않음).

### 6. 사무소에 맞게 설정 확인 (중요)

`config` 폴더의 파일을 메모장으로 열어 고칩니다. 고친 뒤 프로그램을 다시 실행하면 반영됩니다.
**계산·기한에 쓰는 값은 실제 사용 전에 반드시 변호사와 함께 확인하세요.**

| 파일 | 내용 | 확인할 것 |
|---|---|---|
| `office.json` | 사무소 이름, 의뢰인 자료 마감일을 법원 기한보다 며칠 앞당길지 | 사무소 이름 넣기 |
| `plan.json` | 변제계획안 계산 기준 | 기준중위소득(특히 올해 값), 생계비 비율 60%, 할인율 연 5%, 최저변제액 기준 |
| `holidays.json` | 보정 기한 계산용 공휴일 | 대체공휴일·임시공휴일 추가 |
| `courts.json` | 법원 목록, 법원별 메모 | 자주 가는 법원 메모 |
| `questionnaire.json` | 채무 문진 항목 | 필요하면 항목 추가 (지우면 기존 사건 표시가 사라지니 추가만 권장) |
| `correction_rules.json` | 보정명령 분류·추천 서류 규칙 | 사무소에서 자주 받는 보정 문구에 맞게 |

메모장으로 저장할 때 인코딩은 **UTF-8**을 유지하세요. 쉼표·따옴표를 지우면 프로그램이 열리지 않으니 고치기 전에 파일을 복사해 두면 안전합니다.

### 7. (선택) HWP 출력 준비

한글이 설치된 PC면 따로 할 것은 없습니다. 처음 HWP를 만들 때 한글이 "파일에 접근하려 합니다" 창을 띄우면 **모두 허용**을 누르세요.
사무소 채권자목록 양식에 맞춰 출력하려면 아래 "HWP 출력"의 양식 만드는 법을 보세요.

### 8. (선택) 바탕화면 바로가기

`실행.bat` 오른쪽 클릭 → **바로 가기 만들기** → 만들어진 바로 가기를 바탕화면으로 옮깁니다.

## 매일 쓰기

- **시작**: `실행.bat`(또는 바탕화면 바로가기) 더블클릭 → 브라우저에서 로그인.
- **끝내기**: 검은 창을 닫습니다. 브라우저 탭만 닫으면 프로그램은 계속 켜져 있습니다.
- 검은 창이 켜져 있는 동안만 쓸 수 있습니다. 이 PC에서만 열리며, 같은 사무실의 다른 PC에서는 접속할 수 없습니다.

## 업데이트 (새 버전 받기)

1. 프로그램을 끕니다 (검은 창 닫기).
2. **먼저 백업**합니다: `백업.bat` 실행.
3. "2. 프로그램 받기"처럼 새 ZIP을 받아 **새 폴더**에 풉니다 (예: `C:\개인회생_새버전`).
4. 예전 폴더에서 아래를 새 폴더의 같은 자리로 복사합니다.
   - `data\cases.db` — 모든 사건 자료 (**꼭**)
   - `templates\채권자목록_양식.hwp` — 사무소 양식을 쓰는 경우
   - `config` 폴더에서 직접 고친 파일 — 새 버전의 파일과 내용을 비교해 고친 부분만 옮기는 것이 안전합니다
5. 새 폴더의 `실행.bat`을 실행합니다. 새 부품이 있으면 자동으로 설치합니다. 기존 자료는 그대로 열리고, 새 기능에 필요한 표는 자동으로 추가됩니다.
6. 잘 되는 것을 확인한 뒤 예전 폴더를 지웁니다.

git으로 받았다면 `git pull` 후 `실행.bat`을 실행하면 됩니다 (`data`, `output`은 git에 올라가지 않습니다).

## 백업과 PC 옮기기

- **백업**: `백업.bat`을 실행하면 `backup` 폴더에 날짜·시간이 붙은 `cases_….db` 파일이 생깁니다. 주 1회 이상, 그리고 업데이트 전에 하세요.
- **되돌리기**: 프로그램을 끄고, 원하는 백업 파일을 `data\cases.db`로 이름을 바꿔 덮어씁니다.
- **다른 PC로 옮기기**: 새 PC에 1~4단계로 설치한 뒤, `data\cases.db`(와 양식·고친 설정)를 복사합니다.
- 의뢰인 개인정보가 들어 있으므로 백업 파일을 USB·개인 클라우드로 사무소 밖에 가져가지 마세요.
- 출력한 파일은 `output` 폴더에도 남습니다. 필요 없으면 정기적으로 지우세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "Python을 찾을 수 없습니다" | 1단계를 다시 하되 **Add python.exe to PATH**를 체크하세요. 설치 뒤 PC를 다시 시작하면 확실합니다. |
| "설치에 실패했습니다" | 인터넷 연결을 확인하세요. 사무소 방화벽·프록시가 막으면 전산 담당에게 `pypi.org`, `files.pythonhosted.org` 접속 허용을 요청하세요. Python 3.14처럼 너무 새 버전이면 3.12로 다시 설치하세요. |
| 설치 중 오류가 나서 계속 실패 | 프로그램 폴더의 `.venv` 폴더를 지우고 `실행.bat`을 다시 실행하세요 (자료는 지워지지 않습니다). |
| 브라우저가 안 열림 | 주소창에 http://localhost:8501 을 입력하세요. |
| "Port 8501 is already in use" | 이미 켜진 검은 창이 있습니다. 그 창을 쓰거나 닫고 다시 실행하세요. |
| 글자가 깨진 검은 창 | 실행에는 문제없습니다. 안내 문구만 깨진 것입니다. |
| HWP 버튼이 눌리지 않음 | 한글이 설치된 Windows PC에서만 됩니다. 한글을 설치했는데도 안 되면 한글을 한 번 직접 실행했다가 닫고 다시 해 보세요. |
| "Tesseract OCR이 설치되어 있지 않습니다" / "한국어 데이터(kor)가 없습니다" | 3단계를 다시 하세요. Korean 체크를 빠뜨린 경우가 많습니다. |
| 설정 파일을 고친 뒤 프로그램이 안 열림 | 고친 `config` 파일의 쉼표·따옴표를 확인하거나, 복사해 둔 원래 파일로 되돌리세요. |
| 비밀번호를 잊음 | 변호사·관리자 계정의 **계정 관리 → 다른 사람 비밀번호 초기화**. 모든 계정을 잊었다면 **`비밀번호_초기화.bat`** 실행 (위 "5. 계정 만들기"). |

## 업무 순서

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | 사건 목록 | 새 사건 등록 |
| 2 | 사건 기본정보 | 채무자 정보, 관할 법원, 담당 변호사, 목록 기준일 |
| 3 | 채무 문진 | 채무 종류별로 있음/없음/모름 체크 |
| 4 | 신용정보 대조 | 신용정보조회서 PDF를 올려 자동으로 읽거나 직접 입력 (목록에 없는 기관은 한 번에 채권자로 추가 가능) |
| 5 | 채권자 입력 | 채권자별·계약별로 원금, 이자, 지연손해금, 기준일, 발생일, 양도 이력 입력 |
| 6 | 발급대행 요청 목록 | 대행 업체에 보낼 엑셀 출력, 기관별 수령 체크 |
| 6-1 | 부채증명서 대조 | 받은 부채증명서를 올려 금액을 읽고, 입력된 채권과 대조·반영 |
| 7 | 누락 점검 | 경고를 고치거나, 사유를 적고 '확인함' |
| 8 | 미리보기·출력 | 검토 요청 → 변호사 확인 완료 → HWP·엑셀 출력 |
| 8-1 | 변제계획안 | 소득·생계비·재산을 넣으면 월 변제금·채권자별 배분·월별 변제표 계산, 청산가치·최저변제액 검사, 변호사 확정 후 출력 |
| 9 | 보정명령 | 명령문을 항목별로 나누고, 서류 요청 → 답변 작성 → 변호사 승인 → 보정서 출력 |
| 10 | 변경 기록 | 누가 언제 무엇을 바꿨는지, 누가 확인했는지 |

### 누락 점검 규칙
1. 신용정보조회서에 있는데 채권자목록에 없는 기관 (`(주)`, `주식회사`, 띄어쓰기 차이는 무시)
2. 문진에서 "있음"인데 그 분류로 등록된 채권이 없는 항목
3. 부채증명서가 아직 "수령"이 아닌 채권자
4. 양도 전 기관과 양도 후 기관이 둘 다 채권자로 등록된 경우 (중복 의심)
5. 채권마다 금액 기준일이 다른 경우
6. 원금·이자·지연손해금·발생일·기준일이 비어 있는 채권 (0원으로 계산하지 않고 "미확인")
7. 가장 최근 부채증명서의 합계와 입력된 채권 합계가 다른 채권자

### 변호사 확인 규칙
- "변호사 확인 완료"는 **변호사 계정에서만**, **처리 안 된 경고가 0건일 때만** 할 수 있습니다.
- 확인 완료 뒤 채권 내용을 고치면 자동으로 "작성 중"으로 돌아갑니다 (부채증명서 수령 체크는 예외).
- 확인 전에 출력한 파일은 제목과 파일 이름에 **초안**이 붙습니다.
- 합계는 확인된 금액만 더하고, 비어 있는 칸은 "미확인 n건"으로 따로 표시합니다.

## 신용정보조회서 PDF 자동 읽기 (2단계)

신용정보 대조 화면 → "PDF에서 자동으로 읽기" → 파일 올리기 → 읽기.

- 표가 있으면 머리글(기관명·잔액·일자·상품 등)로 열을 찾아 읽고, 표가 없으면 한 줄씩 읽습니다.
- `(단위: 천원)`·`만원` 표시를 찾아 **원 단위로 바꿉니다.** 금액 열은 잔액 → 연체금액 → 금액 순으로 고릅니다.
- **조회기록**(다른 기관이 조회한 기록)은 채권자가 아니므로 읽지 않습니다. 합계·소계 줄도 뺍니다.
- 처음부터 빼 두는 항목: 잔액 0원, 연체정보에 다시 나온 같은 기관, 완전히 같은 중복. 필요하면 체크해서 가져오면 됩니다.
- 읽은 결과는 **바로 저장되지 않습니다.** 원문 그림(읽은 위치에 초록·회색 표시)과 대조해 고르고, 틀린 칸은 표에서 고친 뒤 가져오세요.
- 이미 있는 같은 기관·같은 금액은 다시 넣지 않습니다. 가져온 기록은 변경 기록에 남습니다.
- 비밀번호가 걸린 PDF는 비밀번호를 넣고 읽으면 됩니다. 파일은 디스크에 저장하지 않습니다.
- 글자가 없는 스캔본 쪽은 읽지 못하고 알려 줍니다. 이런 쪽은 직접 입력하세요.

발급처(한국신용정보원, NICE, KCB 등)마다 양식이 달라 잘 안 읽히는 경우가 있습니다. 그때는 `core/credit_pdf.py` 위쪽의
키워드 목록(`INST_HEADERS`, `AMOUNT_HEADERS` 등)을 고치거나, 개인정보를 가린 샘플로 양식에 맞춰 조정하세요.

## 부채증명서 OCR·금액 대조 (3단계)

부채증명서 대조 화면 → 파일 올리기(여러 개 가능) → 읽기 → 한 장씩 확인.

- **전자 발급 PDF**(글자가 들어 있는 PDF)는 OCR 없이 바로 읽습니다.
- **스캔본 PDF·사진(JPG/PNG/TIFF)**은 Tesseract OCR로 읽습니다. 표의 괘선을 지우고 읽는 방식과 가볍게 읽는 방식
  두 가지로 읽어 더 잘 읽힌 쪽을 씁니다.
- 읽는 것: 금액 기준일("○○ 현재"), 계약별 과목·발생일·원금·이자·지연손해금(연체이자)·기타 비용·합계, 채무자 이름.
  "대출금액(최초 대출금)" 열은 갚을 돈이 아니므로 읽지 않습니다.
- 검사: 원금+이자+지연손해금 ≠ 합계, 계약 합 ≠ 합계 줄, 채무자 이름이 없음(다른 사람 서류?), 기준일 없음.
  한 칸만 못 읽었고 합계가 있으면 빼서 계산하고 **추정값**이라고 표시합니다.
- 원문 그림에 읽은 줄을 표시합니다(초록 = 금액, 주황 = 기준일). 틀린 칸은 표에서 고치세요.
- 채권자는 증명서에 적힌 이름(양도 전 기관명 포함)으로 자동 선택되고, 계약은 발생일 → 과목 이름 → 순서로
  기존 채권에 맞춰집니다. '반영할 채권'에서 바꿀 수 있습니다.
- **확인하고 채권에 반영**: 원금·이자·지연손해금·기준일·근거 서류를 채권에 넣고, 부채증명서 상태를 '수령'으로 바꿉니다.
  **증명서만 기록**: 채권은 그대로 두고 기록만 남깁니다. 금액이 다르면 누락 점검(R7)에 경고가 뜹니다.
- 대행 업체가 여러 증명서를 한 파일로 보냈으면 "쪽마다 따로 읽기"를 체크하세요. 옆으로 누운 스캔본은 회전을 고르세요.

스캔본을 읽으려면 Tesseract OCR이 있어야 합니다 (위 "설치 3단계").

스캔 품질이 나쁘면(흐림, 기울어짐, 도장이 숫자를 가림) 잘못 읽을 수 있습니다. 반드시 원문과 대조하세요.
양식이 달라 잘 안 읽히는 기관이 있으면 `core/debt_cert.py` 위쪽의 `COLUMN_WORDS` 키워드를 고치면 됩니다.

## 보정명령 관리 (4단계)

보정명령 화면 → "새 보정명령 등록" → 명령문 붙여 넣기 또는 파일(전자소송 PDF·스캔본·사진) 올리기 → 송달일 입력 → 명령문 읽기.

- **항목 나누기**: `1.` `가.` `①` 번호로 항목을 나눕니다. `1. 채권자목록 관련 / 가. … / 나. …`는 `1-가`, `1-나`로 나뉘고
  큰 제목이 함께 남습니다. 잘못 나뉜 곳은 등록 전에 표에서 고치세요.
- **분류·서류 추천**: 채권자목록, 재산목록, 수입·지출, 변제계획안, 진술서·소명, 기타로 분류하고, 명령 문구에 맞는
  서류(거래내역서, 급여명세서, 해약환급금 증명서 등)와 답변 첫 문장을 넣어 둡니다. 규칙은 `config/correction_rules.json`.
- **기한**: 송달일 다음 날부터 세어 정한 일수째. 마지막 날이 토·일·공휴일이면 다음 평일(민법 제161조).
  공휴일은 `config/holidays.json` — **대체·임시공휴일은 직접 확인해 고치세요.** 기한은 화면에서 직접 고칠 수 있습니다.
  사건 목록 맨 위와 왼쪽 메뉴에 D-day가 나옵니다(3일 이내 빨강, 7일 이내 주황).
- **자료 요청**: 서류별로 요청 전 / 요청함 / 받음 / 생략(사유 필수). 의뢰인 안내문(문자·카톡용)을 만들어 주며,
  마감일은 법원 기한보다 며칠 앞입니다(`config/office.json`의 `client_lead_days`, 사무소 이름도 여기서).
- **승인**: 모든 항목에 답변이 있고 서류가 모두 '받음' 또는 '생략'이어야 변호사 계정에서 승인할 수 있습니다.
  승인 뒤 답변·서류를 고치면 '작성 중'으로 돌아갑니다. 승인 → 제출 완료로 표시하면 기한 알림에서 빠집니다.
- **보정서 출력**: 미리보기, HTML, 전자소송 붙여넣기용 글(TXT), HWP(한글 설치 PC). 승인 전에는 [초안] 표시.
  첨부서류 목록은 '받음' 처리한 서류로 자동으로 만들어집니다.

## 변제계획안 (5단계)

변제계획안 화면 → 소득·생계비, 변제 조건, 채권 구분, 재산을 넣고 "저장하고 계산".

- **생계비** = 기준중위소득(연도·가구원 수) × 60% + 추가 생계비. 직접 입력할 수도 있습니다.
- **월 변제금** = 월 평균 소득(실수령) − 생계비. 직접 정할 수도 있지만 가용소득보다 적으면 경고합니다.
- **채권 구분**: 일반 / 우선(조세 등, 세금 분류 채권은 자동으로 우선) / 제외(별제권 등).
  우선채권을 먼저 전액 갚고, 남는 돈은 일반채권에 채권액 비율로 나눕니다(원 단위 내림, 남는 원은 큰 채권부터).
  채권액은 '원금+이자+지연손해금' 또는 '원금만' 중 고릅니다. 금액이 '미확인'인 채권이 있으면 계산하지 않습니다.
- **검사**: 총 변제예정액의 현재가치(연 5%, 월 단위 할인) ≥ 청산가치, 총 변제예정액 ≥ 최저변제액.
  기준을 못 넘으면 몇 개월로 늘리면 되는지, 60개월로도 안 되면 월 변제금이 얼마 필요한지 알려 줍니다.
- **확정**: 채권자목록이 '변호사 확인 완료'이고 두 검사를 모두 넘어야 변호사 계정에서 확정됩니다.
  확정 뒤 입력값이나 **채권자목록이 바뀌면** 자동으로 '작성 중'으로 돌아갑니다.
- **출력**: 계산 근거표 엑셀(요약·채권자별·월별 변제표·청산가치), 변제계획안 HTML·HWP. 확정 전에는 [초안].

**계산 기준은 `config/plan.json`에 있습니다. 기준중위소득(특히 2026년 값), 생계비 비율, 할인율, 최저변제액 기준은
법령·고시·관할 법원 실무와 같은지 반드시 확인하고 고치세요.** 이 프로그램의 계산은 초안이며 최종 판단은 변호사가 합니다.

## HWP 출력

한글(한컴오피스)이 설치된 PC에서만 됩니다. 두 가지 방식이 있습니다.

**A. 양식 없이 (기본)**: 프로그램이 표를 만들어 HWP로 저장합니다.

**B. 사무소 양식 사용**: `templates/채권자목록_양식.hwp` 파일을 두면 그 양식의 누름틀에 내용을 채웁니다.
양식 만드는 법: 한글에서 양식을 열고, 채울 자리에 `입력 → 개체 → 누름틀`을 넣은 뒤 누름틀 고치기에서 **필드 이름**을 아래처럼 지정합니다.

- 머리글: `사건번호`, `채무자`, `법원`, `기준일`, `작성일`, `초안표시`
- 표의 한 행: `번호`, `채권자`, `주소`, `연락처`, `원인`, `발생일`, `원금`, `이자`, `지연손해금`, `합계`, `산정기준일`, `비고`
  → 이 행을 필요한 줄 수(예: 40줄)만큼 복사해 두세요. 같은 이름의 누름틀을 위에서부터 차례로 채웁니다.
- 합계 행: `합계_원금`, `합계_이자`, `합계_지연손해금`, `합계_합계`, `미확인건수`

한글이 "파일에 접근하려 합니다" 창을 띄우면 "모두 허용"을 누르세요. 이 창을 없애려면 한컴의
보안 모듈(FilePathCheckerModule)을 등록하면 됩니다.

## 개발 현황과 테스트

설계 문서의 기능 우선순위 1~5단계(채권자목록, 신용정보조회서 PDF, 부채증명서 OCR, 보정명령, 변제계획안)를 모두 만들었습니다.
아직 실제 자료로는 시험하지 않았으므로, 처음에는 사건 몇 건을 기존 방식과 함께 처리하며 결과를 비교하세요.

개발자용 자동 시험: `pip install -r requirements.txt pytest` 후 `python -m pytest` (스캔본 시험은 Tesseract가 있어야 실행됨).
